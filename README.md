# Ритм — трекер лекарств

Статический сайт опубликован на GitHub Pages. Пока облако не подключено, лекарства и отметки хранятся в браузере. Прекращение приёма задаёт дату окончания: препарат и отметки с этой даты удаляются, более ранняя история остаётся. Экспорт скачивает JSON-резервную копию; импорт заменяет локальные данные и после входа в аккаунт также загружает их в облако.

## Подключение Supabase

1. Создайте проект на [supabase.com](https://supabase.com/).
2. Откройте **SQL Editor** в проекте и выполните содержимое [`supabase/schema.sql`](supabase/schema.sql). Таблица включает Row Level Security: каждый аккаунт может читать и менять только собственную запись.
3. В Supabase откройте **Project Settings → API Keys**. Скопируйте **Project URL** и **publishable key** (в старых проектах ключ может называться `anon`). Не используйте `secret` или `service_role` ключ: он даёт обход правил доступа и не должен попадать в браузер.
4. В **Authentication → URL Configuration** задайте Site URL `https://bddddshch.github.io/tabtrak/` и добавьте этот же адрес в Redirect URLs. Он используется для подтверждения почты и сброса пароля; ссылки не должны вести на `localhost`.
5. Откройте опубликованный сайт, нажмите **Облако**, вставьте Project URL и publishable key и нажмите **Сохранить подключение**.
6. Введите почту и пароль, затем выберите **Создать аккаунт**. Если включено подтверждение почты, подтвердите письмо; после перехода обратно на сайт нажмите **Облако → Войти**.

При первом входе локальные и облачные записи объединяются по идентификаторам лекарств и датам приёма. В дальнейшем изменения автоматически отправляются в облако; на другом устройстве войдите в тот же аккаунт. Кнопка **Синхронизировать сейчас** загружает актуальную облачную копию на открытое устройство.

Если забыли пароль аккаунта трекера, нажмите **Облако**, введите адрес почты аккаунта и выберите **Забыли пароль?**. Перейдите по ссылке из письма: сайт предложит задать новый пароль. Приложение передаёт Supabase точный адрес `https://bddddshch.github.io/tabtrak/`; в настройках проекта Site URL и Redirect URLs также должны содержать этот адрес. Если Supabase продолжает формировать ссылку с `localhost`, проверьте **Authentication → URL Configuration** и шаблон письма **Authentication → Email Templates → Reset Password** на старый адрес.

Публичный ключ Supabase предназначен для клиентских приложений; безопасность данных обеспечивает таблица и политики RLS. Никогда не публикуйте пароль пользователя, secret key или service role key.
